매매 복기를 엑셀로 해 봤다면 pandas는 **그 엑셀을 코드로 조종하는 것**이다. 3-3에서 CSV를 `for` 루프와 딕셔너리로 집계했는데, 열이 열 개, 행이 수천 개가 되면 그 코드는 금방 길고 느려진다. pandas는 "열 전체를 한 번에" 계산한다. 공식 튜토리얼 표현으로 "연산은 요소별로 이루어지므로 행을 돌 필요가 없다."

## 핵심 개념

### 1. pandas, DataFrame, Series

**한 줄 정의**: pandas는 표 데이터 라이브러리이고, DataFrame은 행·열이 있는 표, Series는 그 표의 한 열(또는 한 행)이다.

**비유**: 엑셀 시트 하나가 DataFrame, 한 열이 Series, 맨 왼쪽 행 번호(또는 날짜)가 인덱스(index).

**실제 예시** ("10 minutes to pandas"의 관례):

```python
import pandas as pd                        # 공식 문서의 별명 관례 (3-4의 import as)

s = pd.Series([1, 3, 5, 6, 8])             # 열 하나
df = pd.DataFrame({"name": ["삼성전자", "카카오"], "close": [73500, 39500]})
df["close"]                                # Series. df[["name", "close"]]는 DataFrame
df.index, df.columns, df.dtypes            # 행 번호, 열 이름, 열별 자료형
```

설치는 가상환경에서 `python -m pip install pandas`, 그래프용으로 `python -m pip install -U matplotlib`(matplotlib 설치 문서의 명령). pandas 설치 문서는 matplotlib을 "plot" 선택 의존성으로, openpyxl을 Excel 읽기/쓰기용으로 적고 있다.

**왜 중요한가**: 클로드가 데이터 분석 코드를 쓰면 거의 항상 `pd.`로 시작한다. DataFrame/Series 구분이 되어야 에러 메시지가 읽힌다.

### 2. 읽고 첫 점검: `read_csv`, `head`, `info`, `describe`

**한 줄 정의**: `pd.read_csv()`가 CSV를 DataFrame으로 읽고, `head`/`tail`/`info`/`dtypes`/`describe`가 "제대로 읽혔는지"를 보여 준다.

**실제 예시** (입문 튜토리얼 "표 데이터 읽고 쓰기"):

```python
df = pd.read_csv("prices.csv", parse_dates=["date"], index_col="date")   # 날짜 열을 날짜형으로, 인덱스로
df.head()            # 앞 5행.  df.tail(3)은 뒤 3행
df.info()            # 행 수, 열별 비어 있지 않은 값 수, 자료형
df.describe()        # 숫자 열의 개수·평균·표준편차·최소·사분위·최대
df.to_csv("out.csv") # 저장. df.to_excel("out.xlsx", sheet_name="Sheet1")는 openpyxl 필요
```

튜토리얼의 요약: "다양한 형식에서 읽기는 `read_*` 함수, 내보내기는 `to_*` 메서드. `head`/`tail`/`info`와 `dtypes`는 첫 점검에 편리하다." `parse_dates`를 빼면 날짜가 문자열(`object`)로 들어와 날짜 계산이 안 된다. 시계열 튜토리얼: `pd.to_datetime(df["date"])`로 나중에 바꿔도 된다.

**왜 중요한가**: 데이터 사고의 대부분은 "숫자가 문자열로 읽힘", "날짜가 문자열로 읽힘"이다. `info()` 한 번이 그걸 잡는다.

### 3. 고르기: 열, 조건, `loc`/`iloc`

**한 줄 정의**: 대괄호로 열을 고르고, 대괄호 안에 조건식을 넣어 행을 거르며, `loc`는 이름 기준, `iloc`는 위치 기준이다.

**실제 예시** (입문 튜토리얼 "부분 집합 고르기"):

```python
df["close"]                                  # 열 하나
df[["open", "close"]]                        # 열 여러 개 (리스트로)
df[df["close"] > 72000]                      # 조건에 맞는 행만 (1-6의 filter)
df[df["volume"].notna()]                     # 비어 있지 않은 행만
df[(df["close"] > 72000) | (df["volume"] > 20_000_000)]   # 또는: |, 그리고: &, 각 조건은 괄호
df.loc[df["close"] > 72000, "volume"]        # 조건 행 × 이름으로 고른 열
df.iloc[0:5, 0:2]                            # 위치: 앞 5행, 앞 2열
df.loc["2026-10-15"]                         # 인덱스가 날짜면 날짜로 행 선택
```

튜토리얼 요약: "부분 집합을 고를 때는 대괄호 `[]`. `loc`는 라벨 기준, `iloc`는 위치 기준." `df["close"] > 72000`은 행마다 True/False인 Series이고, 그걸 대괄호에 넣으면 True인 행만 남는다. 3-2의 진릿값 개념이 열 단위로 확장된 것이다.

### 4. 계산하기: 열 연산, 통계, `shift`, `rolling`

**한 줄 정의**: 열끼리의 사칙연산은 행마다 동시에 적용되고, 결과를 `df["새열"] = 식`으로 붙인다.

**실제 예시** (입문 튜토리얼 "새 열 만들기", 사용자 가이드 "기본 기능", "윈도 연산", "시계열"):

```python
df["range"] = df["high"] - df["low"]                  # 요소별 연산, 루프 없음
df["ret"] = df["close"] / df["close"].shift(1) - 1    # shift(1): 한 행 아래로 밀기 → 전일 종가. 일간 수익률
df["ma5"] = df["close"].rolling(window=5).mean()      # 5일 이동평균 (앞 4행은 NaN)
df["close"].mean(), df["close"].std(), df["ret"].max()
df["ret"].idxmax(), df["ret"].idxmin()                # 최고·최저 수익률이 난 날짜(인덱스)
df["ret"].cumsum()                                    # 누적 합
df.sort_values(by="ret", ascending=False).head(3)     # 수익률 상위 3일
df.nlargest(3, "volume")                              # 거래량 상위 3행
df["above_ma5"].value_counts()                        # 범주별 개수 (True/False 각각 며칠)
```

`rolling`은 윈도 연산 문서대로 "현재 관측에서 윈도 길이만큼 뒤를 돌아본" 묶음에 `mean()` 같은 계산을 한다. 첫 몇 행은 자료가 부족해 `NaN`(빈 값)이다. `shift`는 시계열 문서의 "shifting/lagging"으로, "모든 pandas 객체에서 쓸 수 있다."

**왜 중요한가**: 이동평균·수익률·누적 손익이 전부 한 줄씩이다. 3-3에서 열 줄 걸리던 "종목별 합계"도 아래 `groupby` 한 줄이다.

### 5. 묶기: `groupby`, 날짜 속성, `resample`

**실제 예시** (입문 튜토리얼 "요약 통계", "시계열"):

```python
trades = pd.read_csv("trades.csv", parse_dates=["date"])
trades["profit"] = (trades["sell"] - trades["buy"]) * trades["qty"]
trades.groupby("name")["profit"].sum()               # 종목별 손익 (3-3 실습 3의 한 줄 버전)
trades.groupby(["name", "date"])["profit"].mean()    # 두 기준으로
trades["month"] = trades["date"].dt.month            # 날짜 열의 월. .dt.day_of_week는 요일(월=0)
df["close"].resample("MS").max()                     # 날짜 인덱스를 월 시작(MS) 단위로 묶어 최대값
```

튜토리얼 요약: "`groupby`는 split-apply-combine(나누고-적용하고-합치기) 패턴", "`value_counts`는 범주별 개수의 지름길", "Resample은 시계열의 빈도를 바꾸는 강력한 메서드."

### 6. 그래프: `.plot()`과 저장

**한 줄 정의**: Series/DataFrame의 `.plot()`이 matplotlib 그래프를 그리고, `fig.savefig("파일.png")`로 저장한다.

**실제 예시** (입문 튜토리얼 "그래프 만들기", matplotlib "Introduction to Figures"):

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(12, 4))      # Figure(도화지)와 Axes(그래프 영역) 하나
df[["close", "ma5"]].plot(ax=ax)             # 열마다 선 하나
ax.set_ylabel("KRW")
fig.savefig("close_ma5.png", dpi=200)        # 현재 폴더에 PNG 저장
plt.show()                                   # 창으로 보기. "창을 닫을 때까지 스크립트를 멈춘다"
```

튜토리얼 요약: "`.plot.*` 메서드는 Series와 DataFrame 모두에 쓸 수 있고, 기본으로 열마다 다른 요소(선, 상자…)로 그리며, pandas가 만든 그래프는 전부 Matplotlib 객체다." 그래서 matplotlib의 `ax.set_ylabel`, `fig.savefig`가 그대로 통한다. 산점도는 `df.plot.scatter(x="volume", y="ret")`, 상자 그림은 `df.plot.box()`.

**왜 중요한가**: 4-4의 알림에 그래프 PNG를 붙이고, 4단계 기획부의 월별 리포트에 넣는다. 눈으로 보면 숫자 표에서 못 본 이상치가 보인다.

### 실습 3. 수익률과 이동평균 (40분)

```python
# analyze.py
import pandas as pd

df = pd.read_csv("prices.csv", parse_dates=["date"], index_col="date")
df["ret"] = df["close"] / df["close"].shift(1) - 1
df["ma5"] = df["close"].rolling(window=5).mean()
df["above_ma5"] = df["close"] > df["ma5"]

print(df[["close", "ret", "ma5", "above_ma5"]].round(4))
print("\n평균 일간 수익률:", f"{df['ret'].mean():.2%}", "/ 변동성(표준편차):", f"{df['ret'].std():.2%}")
print("최고:", df["ret"].idxmax().date(), f"{df['ret'].max():+.2%}",
      "/ 최저:", df["ret"].idxmin().date(), f"{df['ret'].min():+.2%}")
print("누적 수익률:", f"{df['ret'].cumsum().iloc[-1]:+.2%}")
print("\n5일선 위에서 마감한 날:", int(df["above_ma5"].sum()), "일")
big_up = df[df["ret"] > 0.02]
print("2% 이상 오른 날:\n", big_up[["close", "ret", "volume"]])
df.to_csv("prices_analyzed.csv")
```

`ret`의 첫 행과 `ma5`의 앞 4행이 `NaN`인 이유를 설명할 수 있어야 한다(전일이 없고, 5일치가 안 모였다). `True`의 합이 개수가 되는 것(`sum()`)은 3-2의 `bool`이 숫자 1로 취급되기 때문이다.

### 실습 4. 체결 내역 집계 (30분)

3-3 실습 3의 `trades.csv`를 pandas로 다시 집계한다.

```python
# trades_pd.py
import pandas as pd

t = pd.read_csv("trades.csv", parse_dates=["date"])
t["profit"] = (t["sell"] - t["buy"]) * t["qty"]
t["ret"] = t["sell"] / t["buy"] - 1
print(t.groupby("name")["profit"].sum().sort_values(ascending=False))
print(t.groupby("date")[["profit"]].sum())
print("승률:", f"{(t['profit'] > 0).mean():.0%}", "/ 건수:", len(t))
print(t.groupby("name").agg(trades=("profit", "count"), total=("profit", "sum"), avg_ret=("ret", "mean")).round(4))
```

3-3에서 딕셔너리로 열 줄 걸린 집계가 `groupby` 한 줄이다. `agg`는 튜토리얼의 "여러 통계를 한 번에" 방식으로, `새이름=("열", "통계")` 꼴로 적는다.

## 흔한 실수와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `ModuleNotFoundError: No module named 'pandas'` | 가상환경 미활성 또는 미설치 | `(.venv)` 확인 후 `python -m pip install pandas matplotlib` |
| `KeyError: 'date'` | `index_col="date"`로 읽어 열이 아니라 인덱스가 됨 | `df.index`로 접근, 또는 `index_col` 제거 |
| 날짜 계산·`resample`이 안 됨 | 날짜가 문자열(`object`) | `parse_dates=[...]` 또는 `pd.to_datetime()` |
| 조건 두 개를 `and`로 묶었더니 에러 | Series 조건은 `&`, `\|`로, 각각 괄호 | `df[(조건1) & (조건2)]` |
| 첫 행들이 `NaN` | `shift`, `rolling`은 앞 자료가 없음 | 정상. 계산에서 자동으로 제외된다 |
| 그래프 한글이 네모 | 기본 글꼴에 한글 없음 | 라벨을 영문으로, 또는 글꼴 설정(공식 문서 확인) |
| `plt.show()` 뒤 코드가 안 돎 | 창을 닫을 때까지 멈춘다 | 파일 저장은 `savefig`로 먼저, `show()`는 맨 끝 |

## 확인 퀴즈

**1. `df["close"]`와 `df[["close"]]`의 차이는?**

<details><summary>정답과 해설</summary>

앞은 Series(열 하나), 뒤는 열이 하나뿐인 DataFrame. 대괄호 안에 리스트를 넣으면 DataFrame이 된다.
</details>

**2. `df[df["ret"] > 0.02]`가 동작하는 원리를 두 단계로 설명하면?**

<details><summary>정답과 해설</summary>

(1) `df["ret"] > 0.02`는 행마다 True/False인 Series를 만든다. (2) 그 Series를 대괄호에 넣으면 True인 행만 남는다. 튜토리얼의 `titanic[titanic["Age"] > 35]`와 같은 구조.
</details>

**3. `df["close"].rolling(window=5).mean()`의 처음 4개 값이 `NaN`인 이유는?**

<details><summary>정답과 해설</summary>

rolling은 "현재 관측에서 윈도 길이만큼 뒤를 돌아본" 5개로 평균을 내는데, 앞 4행은 5개가 모이지 않아 계산할 수 없다.
</details>

**4. `loc`와 `iloc`의 차이는?**

<details><summary>정답과 해설</summary>

`loc`는 라벨(행 이름·열 이름) 기준, `iloc`는 위치(0부터 세는 정수) 기준. 튜토리얼 요약 그대로.
</details>

**5. pandas로 그린 그래프에 `ax.set_title()`을 쓸 수 있는 이유는?**

<details><summary>정답과 해설</summary>

튜토리얼: "pandas가 만든 그래프는 전부 Matplotlib 객체"이기 때문이다. `.plot(ax=ax)`로 Axes를 넘기면 matplotlib 메서드와 `fig.savefig`가 그대로 통한다.
</details>
