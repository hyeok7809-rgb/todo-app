## 왜 배우나 (나에게 어떤 쓸모)

지금까지 만든 가계부 앱은 **브라우저 안**에서 돈다. 브라우저는 매장 같은 곳이라 손님(사용자)이 눌러야 움직이고, 내 컴퓨터의 파일을 마음대로 읽거나 새벽 3시에 혼자 깨어나 일하지 못한다. 목표 1번 "내 매매·생활 자동화"는 정확히 그 반대다. 장 마감 뒤 체결 내역 CSV로 복기표를 만들고, 아침마다 시세를 가져와 텔레그램으로 보내고, 가계부 백업을 날짜별로 저장하는 "뒷방에서 혼자 돌아가는 비서"가 파이썬이다.

공식 튜토리얼 첫 장의 첫 문장이 이 과정의 목적 그대로다. "컴퓨터로 일을 많이 하다 보면 결국 자동화하고 싶은 작업이 생긴다." 왜 파이썬이냐의 답도 같은 페이지에 있다. 인터프리터 언어라 "컴파일과 링크가 필요 없고", "유연한 배열과 딕셔너리 같은 고수준 자료형이 내장"되어 있으며, 문법이 단순해 짧게 쓴다. 3-6의 pandas, 4-3의 한국투자증권 API, 10단원의 Claude Agent SDK 예제가 전부 이 언어 위에서 돈다. 이름은 뱀이 아니라 BBC 코미디 "Monty Python's Flying Circus"에서 왔다.

## 핵심 개념

### 1. 파이썬(Python): 읽기 쉬운 자동화 언어

**한 줄 정의**: 들여쓰기로 코드 블록을 구분하는, 인터프리터(interpreter) 방식의 범용 프로그래밍 언어.

**비유**: JavaScript가 "매장 직원"(브라우저 안에서 손님 상대)이라면 파이썬은 "본사 사무직원"(내 컴퓨터·서버에서 장부 정리, 보고서, 외부 연락). 하는 일의 원리는 같고 근무지와 말투가 다르다.

**실제 예시**: app.js의 `calculateBalance()` 반복문을 파이썬으로 옮기면 이렇다.

```python
balance = 0
for entry in entries:                      # JS: for (const entry of entries) {
    if entry["type"] == "income":          # JS: if (entry.type === "income") {
        balance = balance + entry["amount"]
    else:
        balance = balance - entry["amount"]
```

중괄호 `{ }`와 세미콜론이 사라지고, 대신 **들여쓰기(indentation)** 가 블록을 정한다. 공식 튜토리얼: "루프의 본문은 들여쓰기한다. 들여쓰기는 파이썬이 문장을 묶는 방식이다." 공식 스타일 가이드(PEP 8)는 "들여쓰기 한 단계에 공백 4칸"을 쓰라고 한다. 탭 대신 공백이다. VS Code는 파이썬 파일에서 기본으로 그렇게 넣어 준다.

**왜 중요한가**: 들여쓰기가 문법이므로 한 칸만 어긋나도 에러다. 반대로 말하면 "보기 좋은 코드 = 돌아가는 코드"라 남의 코드(클로드가 써 준 코드 포함)를 읽기 쉽다.

### 2. 실행하는 세 가지 방법

**한 줄 정의**: 파이썬 코드는 (1) 대화형으로 한 줄씩, (2) `.py` 파일을 통째로, (3) 터미널에서 한 줄짜리 명령으로 실행할 수 있다.

**비유**: (1)은 전화로 묻고 바로 답 듣기, (2)는 업무 지시서를 통째로 넘기기, (3)은 쪽지 한 장.

**실제 예시** (공식 튜토리얼 "인터프리터 사용하기"와 명령줄 문서 기준):

| 방법 | Mac | Windows(PowerShell) | 언제 |
|---|---|---|---|
| 대화형(REPL) | `python3` | `python` 또는 `py` | 문법 실험, 계산기 |
| 스크립트 | `python3 hello.py` | `python hello.py` | 실제 자동화 |
| 한 줄 | `python3 -c "print(1+1)"` | `python -c "print(1+1)"` | 빠른 확인 |

대화형 모드는 `>>>` 프롬프트, 이어지는 줄은 `...`로 표시되고 `quit()`로 나간다. `-c`는 "명령 문자열의 코드를 실행", `-m`은 "모듈을 찾아 `__main__`으로 실행"이다(명령줄 문서). 아래 venv와 pip를 전부 `python -m ...` 꼴로 부른다. Windows는 `py` 런처로 `py hello.py`, `py --list`도 되며 "추가 인자는 그대로 파이썬에 전달된다". Mac은 0-3대로 `python3`다. 코드 블록은 Mac → Windows 순서, 같으면 한 번만 적는다.

**왜 중요한가**: 자동화 스크립트는 결국 (2)로 돌리고, 4-4에서 스케줄러가 바로 이 `python 파일.py` 명령을 정해진 시각에 대신 쳐 준다.

### 3. 가상환경(venv): 프로젝트별 독립 작업실

**한 줄 정의**: 가상환경(virtual environment)은 "특정 파이썬 버전의 설치본을 담은, 자기만의 디렉터리"(공식 튜토리얼)로, 프로젝트마다 패키지를 따로 설치해 서로 섞이지 않게 한다.

**비유**: 단타 계좌와 장기 계좌를 분리하는 이유와 같다. 한 계좌에 다 넣으면 "이 손익이 어느 전략 것인지" 모르고, 한쪽 실수가 다른 쪽을 망친다. 프로젝트 A는 pandas 최신판, 프로젝트 B는 옛 버전이 필요할 때 가상환경이 없으면 하나를 지워야 한다.

**실제 예시** (공식 튜토리얼과 `venv` 라이브러리 문서):

```bash
# 만들기 (프로젝트 폴더 안에서)
python3 -m venv .venv
# 켜기
source .venv/bin/activate
# 끄기
deactivate
```
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
deactivate
```

켜지면 프롬프트 앞에 `(.venv)`가 붙고, 그때부터 `python`과 `pip`는 이 폴더 안의 것을 가리킨다. 이름은 관례적으로 `.venv`(숨김 폴더라 거치적거리지 않는다) 또는 `venv`.

`venv` 문서의 규칙 둘: 가상환경 폴더는 **"Git 같은 버전 관리에 넣지 않는다"**, 그리고 **"옮기거나 복사할 수 없다. 목적지에서 똑같이 다시 만든다."** USB로 옮기면 깨지니 `requirements.txt`를 들고 가서 재생성한다. Windows PowerShell이 스크립트 실행을 막으면 문서의 해결 명령 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`를 한 번 친다.

**왜 중요한가**: 이 과정에서 requests(3-5), pandas·matplotlib(3-6), 4단원의 API 라이브러리, 10단원의 Anthropic SDK를 설치한다. 한 바구니에 다 넣으면 몇 달 뒤 "뭐가 왜 깔렸는지" 모르게 되고, 클로드에게 "환경 재현해 줘"라고 시킬 때도 `requirements.txt` 하나면 된다.

### 4. pip와 패키지: 남이 만든 부품 가져오기

**한 줄 정의**: pip는 파이썬 패키지 설치 도구이고, 패키지(package)는 PyPI(pypi.org)라는 공개 창고에 올라온 남의 코드 묶음이다.

**비유**: 0-3에서 npm을 "부품 도매상"이라 했다. pip는 파이썬 쪽 도매상이다. 시세 조회, 표 계산, 그래프를 직접 만드는 대신 검증된 부품을 사 온다.

**실제 예시** (공식 튜토리얼 "pip로 패키지 관리하기", pip 사용자 가이드):

| 할 일 | 명령 |
|---|---|
| 설치 / 업그레이드 | `python -m pip install requests` / `... install --upgrade requests` |
| 설치된 목록 | `python -m pip list` |
| 한 패키지 정보 | `python -m pip show requests` |
| 목록을 파일로 저장 | `python -m pip freeze > requirements.txt` |
| 파일대로 설치 | `python -m pip install -r requirements.txt` |
| 삭제 | `python -m pip uninstall requests` |

왜 `pip`가 아니라 `python -m pip`인가. pip 가이드: "`python -m pip`는 당신이 `python`으로 지정한 바로 그 인터프리터로 pip를 실행한다." 파이썬이 둘 이상이면 `pip`가 엉뚱한 쪽에 설치할 수 있는데 `-m`이 그 사고를 막는다. `requirements.txt`는 "pip freeze 결과를 담아 두는 파일"로, 한 줄에 `requests==2.34.2` 같은 꼴이다(pypi.org의 requests 최신 버전 2.34.2, 2026-10-21 확인).

**왜 중요한가**: 자동화의 8할은 "좋은 부품 찾아 조립"이고, 어떤 부품을 어디서 받았는지 적어 두는 습관(12-2 보안)이 `requirements.txt`에서 시작된다.

### 5. VS Code에서 파이썬 쓰기

**한 줄 정의**: VS Code의 Python 확장(extension)을 설치하면 인터프리터 선택, 가상환경 자동 활성화, 실행 버튼이 생긴다.

**실제 예시** (VS Code 공식 Python 문서): 확장 보기(`Ctrl+Shift+X` / `Cmd+Shift+X`)에서 **Python** 확장을 설치한다. 명령 팔레트(`Ctrl+Shift+P` / `Cmd+Shift+P`)의 **Python: Select Interpreter**로 `.venv`를 고르면 "상태 표시줄에서 어떤 환경이 활성인지" 보이고, "확장이 선택한 환경을 터미널에서 자동으로 활성화한다." 아직 가상환경이 없으면 **Python: Create Environment**(첫 질문 "Choose manager: venv or conda")로 만든다. 실행은 편집기 오른쪽 위 **Run Python File** 버튼, 또는 우클릭 → **Run Python > Run Python File in Terminal**.

**왜 중요한가**: 가상환경 켜는 걸 잊는 실수가 가장 흔한데 VS Code가 대신 해 준다. 외부 터미널에서는 직접 켠다.

### 6. 첫 스크립트의 뼈대

**한 줄 정의**: 파이썬 파일은 위에서 아래로 실행되며, `#` 뒤는 주석, `print()`가 출력, f-string(`f"...{값}..."`)이 문자열에 값을 끼우는 방법이다.

```python
# 주석: 파이썬은 # 뒤를 무시한다
balance = 1500000 - 9000 - 4500         # 변수: 타입 선언 없이 바로 넣는다
print("잔액:", balance)                 # 잔액: 1486500  (쉼표로 이으면 띄어서 출력)
print(f"잔액: {balance:,}원")           # 잔액: 1,486,500원  (:, 는 3자리마다 쉼표)
```

`print()`는 "객체들을 `sep`로 구분하고 `end`를 붙여 출력"하는 내장 함수이고, `{balance:,}`의 `,`는 서식 지정 문서의 "3자리마다 쉼표"다. app.js의 `formatMoney()`가 한 글자로 끝났다. 소스 파일은 기본 UTF-8이라 한글이 그대로 된다.

### 3. 첫 스크립트: 가계부 잔액 (30분)

VS Code로 폴더를 열고(`code .`) `ledger.py`를 만든다.

```python
# ledger.py - 가계부 내역의 잔액과 레벨을 계산한다
entries = [
    {"type": "income", "title": "월급", "amount": 1500000},
    {"type": "expense", "title": "점심", "amount": 9000},
    {"type": "expense", "title": "교통", "amount": 4500},
]

balance = 0
for entry in entries:
    if entry["type"] == "income":
        balance = balance + entry["amount"]
    else:
        balance = balance - entry["amount"]

xp = len(entries) * 10
level = xp // 100 + 1

print(f"내역 {len(entries)}건, 잔액 {balance:,}원")
print(f"Lv.{level} ({xp % 100} / 100)")
```

app.js의 `calculateBalance()`와 `renderLevel()`을 합친 것이다. 터미널에서 실행한다.

```bash
python ledger.py
```

출력: `내역 3건, 잔액 1,486,500원`, `Lv.1 (30 / 100)`. `len()`은 "객체의 길이(항목 수)"를 돌려주는 내장 함수(JavaScript의 `.length`). `entry.type`이 아니라 `entry["type"]`인 이유는 3-3 딕셔너리에서 풀린다.

## 흔한 실수와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| Windows에서 `Activate.ps1`이 "스크립트를 실행할 수 없으므로" 오류 | PowerShell 실행 정책 | `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` 후 재시도 |
| Mac에서 `python`이 없다고 한다 | 가상환경 밖에서는 `python3` | `python3`로 부르거나 가상환경을 켠다 |
| `pip install` 했는데 `import` 시 ModuleNotFoundError | 다른 파이썬에 설치됨 | 항상 `python -m pip`, `(.venv)` 확인 |
| 프롬프트에 `(.venv)`가 안 보인다 | 활성화 안 됨, 또는 새 터미널 | 터미널마다 다시 `activate` |
| 폴더를 옮겼더니 가상환경이 깨짐 | venv는 "옮기거나 복사할 수 없다" | `.venv` 지우고 다시 만든 뒤 `-r requirements.txt` |
| 내 파일을 `random.py`, `json.py`로 지었더니 이상 동작 | 스크립트 폴더가 검색 경로 맨 앞이라 표준 모듈을 가린다(3-4) | 다른 이름으로 바꾼다 |

## 확인 퀴즈

**1. 가계부 앱(app.js)은 잘 돌아간다. 그런데 왜 파이썬을 또 배우나?**

<details><summary>정답과 해설</summary>

브라우저 밖에서, 사용자가 누르지 않아도, 내 컴퓨터의 파일과 외부 API를 상대로 혼자 돌아가는 자동화를 하기 위해서다. 매매 복기 CSV 처리, 시세 알림, 백업 같은 일은 브라우저 앱의 영역이 아니다. 개념은 1단원과 같고 표기만 다르다.
</details>

**2. `python -m pip install requests`에서 `-m`의 뜻과, 그냥 `pip install`보다 권장되는 이유는?**

<details><summary>정답과 해설</summary>

`-m`은 "모듈을 찾아 `__main__`으로 실행"하는 명령줄 옵션이다. pip 가이드에 따르면 `python -m pip`는 "`python`으로 지정한 바로 그 인터프리터"로 pip를 실행하므로, 파이썬이 여럿일 때 엉뚱한 곳에 설치되는 사고를 막는다.
</details>

**3. 가상환경 폴더 `.venv`를 USB에 복사해 다른 컴퓨터에서 쓰면 될까?**

<details><summary>정답과 해설</summary>

안 된다. `venv` 문서는 가상환경을 "옮기거나 복사할 수 없는 것"으로 보고 "목적지에서 똑같이 다시 만들라"고 한다. `requirements.txt`를 가져가서 venv 생성 → 활성화 → `python -m pip install -r requirements.txt`로 재현한다. Git에도 넣지 않는다.
</details>

**4. 프롬프트에 `(.venv)`가 안 보이는 상태에서 `python -m pip install pandas`를 치면 어떻게 되나?**

<details><summary>정답과 해설</summary>

시스템(전역) 파이썬에 설치된다. 프로젝트 가상환경에는 없으므로 나중에 가상환경을 켜고 실행하면 ModuleNotFoundError가 난다. 설치 전에 항상 `(.venv)`를 확인한다.
</details>

**5. 다음 코드의 출력은? `xp = 250` 일 때 `print(xp // 100 + 1, xp % 100)`**

<details><summary>정답과 해설</summary>

`3 50`. `//`는 몫을 내림(250 // 100 = 2), `%`는 나머지(50). `print`는 쉼표로 받은 값들을 공백으로 이어 출력한다.
</details>
