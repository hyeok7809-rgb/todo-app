## 핵심 개념

### 1. 변수와 자료형: 선언 키워드가 없다

**한 줄 정의**: 파이썬 변수는 `이름 = 값`으로 바로 만들고, 값의 종류(자료형)는 값 자체가 정한다.

**비유**: JavaScript의 `const`/`let`은 계좌 개설 서류였다. 파이썬은 서류 없이 이름표만 붙인다. 대신 "안 바뀌는 값"은 이름을 대문자로 써서 사람끼리 약속한다(PEP 8: "상수는 모두 대문자, 단어 사이 밑줄").

**실제 예시**:

```python
balance = 0                    # JS: let balance = 0;
STORAGE_KEY = "ledger"         # JS: const STORAGE_KEY = "ledger";  (파이썬은 관례로 대문자)
title, amount = "점심", 9000   # 다중 할당: 둘을 한 번에
type(amount), type(title), type(3.5), type(True), type(None)
# <class 'int'> <class 'str'> <class 'float'> <class 'bool'> <class 'NoneType'>
```

| 자료형 | 파이썬 | JavaScript(1-2) |
|---|---|---|
| 정수 / 소수 | `int` (`9000`) / `float` (`3.5`) | Number (구분 없음) |
| 문자열 | `str` (`"점심"`, `'점심'`) | String |
| 참/거짓 | `bool` (`True`, `False` 대문자!) | Boolean (`true`, `false`) |
| 없음 | `None` | `null` / `undefined` |

`type()`은 "객체의 자료형을 돌려주는" 내장 함수(JS `typeof`). 튜토리얼: "2, 4, 20 같은 정수는 `int`, 5.0, 1.6처럼 소수부가 있으면 `float`." 이름 짓기는 PEP 8대로 **소문자와 밑줄**(`buy_price`, `calculate_balance`). JS의 camelCase와 다르다.

**왜 중요한가**: 파이썬은 선언이 없어 편하지만, `"9000" + 1`처럼 문자열과 숫자를 섞으면 JS와 달리 **바로 에러**(TypeError)를 낸다. 조용히 틀리는 JS보다 낫다. 입력값은 `int()`/`float()`로 바꿔 쓴다.

### 2. 숫자와 문자열 연산

**한 줄 정의**: 숫자는 `+ - * / // % **`, 문자열은 `+`(잇기), `*`(반복), `[ ]`(인덱스·슬라이스), `len()`으로 다룬다.

**실제 예시** (튜토리얼 "숫자", "문자열"):

```python
17 / 3     # 5.666...  '/'는 항상 float
17 // 3    # 5         몫을 내림 (JS: Math.floor(17 / 3))
17 % 3     # 2         나머지
5 ** 2     # 25        거듭제곱

word = "Python"
word[0], word[-1]   # 'P', 'n'   첫 글자, 뒤에서 첫 글자(음수 인덱스)
word[0:2]           # 'Py'       슬라이스: 0 이상 2 미만
len(word)           # 6
3 * "un" + "ium"    # 'unununium'
word[0] = "J"       # TypeError: 문자열은 바꿀 수 없다(불변). 새로 만들어야 한다
```

f-string 서식은 콜론 뒤에 쓴다(서식 지정 미니 언어 문서).

```python
price, qty, rate = 52000, 10, 0.0288
f"{price * qty:,}원"    # '520,000원'  ',' = 3자리 쉼표
f"{rate:.2%}"           # '2.88%'      '%' = 100배 후 % 기호
f"{3.14159:.3f}"        # '3.142'      'f' = 소수 고정, 3자리
f"[{'매수':>6}]"        # '[    매수]' '>' = 오른쪽 정렬, 폭 6
```

**왜 중요한가**: 매매 복기는 결국 숫자 계산과 "보기 좋게 찍기"다. JS에서 `toLocaleString`, `toFixed`로 하던 걸 f-string 한 줄이 대신한다. `/`가 항상 소수를 돌려준다는 점만 기억하면 정수 나눗셈 버그가 사라진다.

### 3. 조건문: `if` / `elif` / `else`

**한 줄 정의**: 조건이 참이면 들여쓴 블록을 실행한다. 조건 끝에 콜론 `:`, 블록은 들여쓰기.

**실제 예시** (튜토리얼 예제):

```python
x = int(input("숫자를 넣으세요: "))   # input()은 항상 문자열 → int()로 변환
if x < 0:
    x = 0
    print("음수는 0으로 바꿈")
elif x == 0:
    print("영")
else:
    print("양수")
```

app.js의 `if (entry.type === "income") { ... } else { ... }`는 `if entry["type"] == "income":` / `else:`가 된다.

| 역할 | JavaScript | Python |
|---|---|---|
| 같다 / 다르다 | `===` / `!==` | `==` / `!=` (하나뿐) |
| 그리고/또는/아님 | `&&` `\|\|` `!` | `and` `or` `not` |
| 아니면-만약 | `else if` | `elif` |
| 포함 | `arr.includes(x)` | `x in arr` |

**거짓으로 취급되는 값**(표준 자료형 문서 "진릿값 검사"): `None`, `False`, 숫자 0(`0`, `0.0`), 빈 것(`''`, `()`, `[]`, `{}`, `set()`, `range(0)`). 그래서 `if entries:`는 "내역이 하나라도 있으면"이다. 1-3의 JS truthy/falsy와 같은 발상이다. 값에 따라 여러 갈래로 나눌 때는 `match 값:` 아래 `case 400:`, `case 404:`, `case _:`(나머지)를 늘어놓는 `match` 문도 있다(튜토리얼 `http_error` 예제).

**왜 중요한가**: 자동화 스크립트의 핵심은 "조건에 따라 알림을 보낼지 말지"다. `if rate < -0.03 and not alerted:` 같은 줄이 영어처럼 읽힌다.

### 4. 반복문: `for ... in`, `range()`, `while`

**한 줄 정의**: `for 항목 in 목록:`은 요소를 하나씩 꺼내고, `range(n)`은 0부터 n-1까지의 숫자를 만들며, `while 조건:`은 조건이 참인 동안 반복한다.

**비유**: 1-4에서 `for...of`를 "체결 내역을 한 줄씩 넘기며 집계"에 비유했다. 파이썬의 `for ... in`이 그것이다. 고전 `for (let i = 0; ...)`는 파이썬에 없고 `range()`로 대신한다.

**실제 예시** (튜토리얼 "제어 흐름"):

```python
words = ["cat", "window", "defenestrate"]
for w in words:
    print(w, len(w))              # JS: for (const w of words)

for i in range(5):                # 0 1 2 3 4   JS: for (let i = 0; i < 5; i++)
    print(i)
list(range(0, 10, 3))             # [0, 3, 6, 9]   (시작, 끝, 간격)

a, b = 0, 1
while a < 10:                     # 조건이 참인 동안
    print(a, end=",")             # end=","로 줄바꿈 대신 쉼표
    a, b = b, a + b               # 0,1,1,2,3,5,8,
```

`break`는 "가장 안쪽 루프를 빠져나가고", `continue`는 "다음 반복으로 넘어간다"(튜토리얼). 아무것도 안 할 자리에는 `pass`. 번호가 같이 필요하면 `enumerate(목록, start=0)`이 `(번호, 값)` 쌍을, 두 목록을 나란히 돌리려면 `zip()`이 쌍을 만든다. 누적 패턴(1-4)은 `total += entry["amount"]`로 쓰고, 합계만 필요하면 내장 `sum()`이 한 줄로 끝낸다.

**왜 중요한가**: "종목별로 돌면서 조건 맞으면 알림"이 4단원 자동화의 뼈대이고, 그게 `for` + `if` 두 줄이다.

### 5. 함수: `def`, `return`, 기본값, 키워드 인자

**한 줄 정의**: `def 이름(매개변수):` 아래 들여쓴 블록이 함수 본문이고, `return`이 결과를 돌려준다. `return`이 없으면 `None`이 돌아온다.

**비유**: 1-5의 "이름 붙인 작업 묶음". 매매로 치면 "손절 규칙"을 종이에 적어 두고 매번 그대로 수행하는 것. 입력(매수가·매도가·수량)이 달라도 절차는 같다.

**실제 예시**:

```python
def calculate_balance(entries):
    """내역 목록을 받아 잔액(수입 합 - 지출 합)을 돌려준다."""   # 독스트링: 함수 설명
    balance = 0
    for entry in entries:
        if entry["type"] == "income":
            balance += entry["amount"]
        else:
            balance -= entry["amount"]
    return balance

def format_money(number, unit="원"):          # unit은 기본값 인자
    return f"{number:,}{unit}"

format_money(calculate_balance(entries))     # '1,486,500원'
format_money(1500000, unit="KRW")            # 키워드 인자로 지정
```

튜토리얼이 못 박은 사실: "`return`에 식이 없으면 `None`을 돌려준다. 함수 끝까지 가도 `None`." 기본값 인자는 `def ask_ok(prompt, retries=4, ...)`처럼 쓰고, 호출할 때 `parrot(voltage=1000000, action='VOOOOOM')`처럼 **이름을 지정**해 넘길 수 있다. 한 줄짜리 익명 함수는 `lambda a, b: a + b`(JS 화살표 함수의 축소판).

**스코프(scope)**: 튜토리얼대로 "함수 실행은 지역 변수용 새 기호 테이블을 만들고", "함수 안의 모든 대입은 지역 테이블에 저장"되며, "전역 변수에는 함수 안에서 직접 대입할 수 없다"(`global` 선언 없이는). 바깥 변수를 읽을 수는 있지만 `=`로 대입하면 새 지역 변수가 생길 뿐이다. 그래서 1-5와 같은 원칙: **넣어 주고(인자) 받아 온다(return)**.

**왜 중요한가**: 클로드에게 코드를 시킬 때 "함수 하나당 한 가지 일"로 쪼개 달라고 하면 검증이 쉬워진다. 함수 단위로 테스트(12-1)하기 때문이다.

### 6. 한눈에 보는 대조표

| 항목 | JavaScript | Python |
|---|---|---|
| 블록 / 문장 끝 / 주석 | `{ }` / `;` / `//` | 들여쓰기 + 줄 끝 `:` / 줄바꿈 / `#` |
| 변수, 참/거짓/없음 | `let x`, `true` `false` `null` | `x = 값`, `True` `False` `None` |
| 출력, 문자열 끼우기, 길이 | `console.log`, `` `${x}` ``, `.length` | `print`, `f"{x}"`, `len()` |
| 반복, 함수 | `for (const e of arr)`, `function f(a) {}` | `for e in arr:`, `def f(a):` |

### 실습 2. 가계부를 함수로 쪼개기 (40분)

3-1의 `ledger.py`를 함수로 재구성한다. app.js의 `calculateBalance`, `formatMoney`, `renderLevel`에 대응한다.

```python
# ledger.py (v2) - 함수로 쪼갠 가계부
XP_PER_ENTRY = 10
XP_PER_LEVEL = 100

entries = [
    {"type": "income", "title": "월급", "amount": 1500000},
    {"type": "expense", "title": "점심", "amount": 9000},
    {"type": "expense", "title": "교통", "amount": 4500},
    {"type": "expense", "title": "헬스장", "amount": 60000},
]

def calculate_balance(entries):
    balance = 0
    for entry in entries:
        if entry["type"] == "income":
            balance += entry["amount"]
        else:
            balance -= entry["amount"]
    return balance

def format_money(number):
    return f"{number:,}원"

def level_info(xp):
    level = xp // XP_PER_LEVEL + 1
    xp_in_level = xp % XP_PER_LEVEL
    return level, xp_in_level          # 값 두 개를 한꺼번에 돌려준다

def print_report(entries):
    print(f"내역 {len(entries)}건")
    for i, entry in enumerate(entries, start=1):
        sign = "+" if entry["type"] == "income" else "-"
        print(f"{i:>2}. {entry['title']:<6} {sign}{format_money(entry['amount']):>12}")
    print("잔액:", format_money(calculate_balance(entries)))
    level, xp_in_level = level_info(len(entries) * XP_PER_ENTRY)
    print(f"Lv.{level} ({xp_in_level} / {XP_PER_LEVEL})")

print_report(entries)
```

실행하면 번호·제목·금액이 정렬된 표와 `잔액: 1,426,500원`, `Lv.1 (40 / 100)`이 나온다. 새로 나온 것: `return level, xp_in_level`로 여러 값을 돌려주고 다중 할당으로 받기, `enumerate(..., start=1)`로 1번부터 번호 붙이기, `"+" if 조건 else "-"`(한 줄 조건식), f-string 안에서는 바깥과 다른 따옴표(`entry['title']`) 쓰기.

### 실습 3. 매매 손익 계산기 (40분)

`trade.py`를 만든다. 수수료율·세율은 **본인 증권사 기준**을 넣는다(아래 숫자는 예시다).

```python
# trade.py - 한 건의 매매 손익과 수익률
def trade_result(buy, sell, qty, fee_rate=0.0, tax_rate=0.0):
    """순손익과 수익률을 돌려준다. 수수료는 매수·매도 양쪽, 세금은 매도 시."""
    buy_amount = buy * qty
    sell_amount = sell * qty
    fee = (buy_amount + sell_amount) * fee_rate
    tax = sell_amount * tax_rate
    profit = sell_amount - buy_amount - fee - tax
    return profit, profit / buy_amount

def judge(rate, stop=-0.03, target=0.05):
    if rate <= stop:
        return "손절 규칙 위반 여부 확인"
    elif rate >= target:
        return "목표 달성"
    else:
        return "보통"

trades = [
    ("삼성전자", 72000, 73500, 10),
    ("카카오", 41000, 39500, 20),
    ("현대차", 250000, 263000, 2),
]
total = 0
for name, buy, sell, qty in trades:          # 튜플을 네 변수로 바로 풀어 받는다
    profit, rate = trade_result(buy, sell, qty, fee_rate=0.00015, tax_rate=0.0018)
    total += profit
    print(f"{name:<6} {profit:>+10,.0f}원 {rate:>+7.2%}  {judge(rate)}")
print(f"합계 {total:>+,.0f}원")
```

서식 `:>+10,.0f`는 "오른쪽 정렬, 부호 항상 표시, 폭 10, 천 단위 쉼표, 소수 0자리". 카카오 줄에 "손절 규칙 위반 여부 확인"이 붙는지 본다. 기본값 인자 덕분에 `trade_result(72000, 73500, 10)`처럼 수수료 없이도 부를 수 있다.

### 실습 4. 헬스 연속 달성일 (`while`, `break`) (30분)

`streak.py`. 최근 기록을 "오늘부터 거꾸로" 세다가 처음 빠진 날에서 멈춘다.

```python
done = [True, True, False, True, True, True, True]   # 최근 7일, 맨 뒤가 오늘

streak = 0
i = len(done) - 1
while i >= 0:
    if not done[i]:
        break                 # 처음 빠진 날에서 멈춤
    streak += 1
    i -= 1
print(f"연속 {streak}일째")   # 연속 4일째
```

`not done[i]`는 "그날 안 했으면". 같은 일을 `for day in reversed(done):`으로도 쓸 수 있다(튜토리얼 "루프 기법"의 `reversed()`). 로드맵 2단계 인사부(연속 달성일, routine.js의 `routineStreak()`)의 핵심 로직이 이 열 줄이다.

### 실습 5. 입력 받아 계산 (10분)

`buy = int(input("매수가: "))`, `sell = int(input("매도가: "))`를 받아 `print(f"수익률 {(sell - buy) / buy:.2%}")`로 찍는 세 줄짜리 `quick.py`를 만든다. 숫자 대신 글자를 넣으면 `ValueError`가 나는데 그 처리는 3-5에서 한다. 지금은 "입력은 항상 문자열, 계산 전에 `int()`"만 기억한다.

## 흔한 실수와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `SyntaxError: expected ':'` | `if`, `for`, `def` 줄 끝 콜론 누락 | 블록을 여는 줄은 `:`로 끝난다 |
| `IndentationError` | 들여쓰기 칸 수 불일치, 탭·공백 혼용 | 공백 4칸으로 통일 |
| `NameError: name 'true' is not defined` | JS 습관 | `True`, `False`, `None` 대문자 |
| `TypeError: can only concatenate str (not "int") to str` | 문자열 + 숫자 | `int()`로 바꾸거나 f-string |
| `if x = 0:`이 에러 | 대입 `=`와 비교 `==` 혼동 | 조건에는 `==` |
| `&&`, `\|\|`, `!` 에러 | JS 연산자 | `and`, `or`, `not` |
| 함수 결과가 `None` | `return` 누락 | 결과를 `return`으로 돌려준다 |
| 함수 안에서 바깥 변수를 바꿨는데 안 바뀜 | 대입은 지역 변수를 새로 만든다 | 인자로 받고 `return`으로 돌려준다 |

## 확인 퀴즈

**1. JavaScript의 `if (a === b && !c) { ... }`를 파이썬으로 쓰면?**

<details><summary>정답과 해설</summary>

`if a == b and not c:` 다음 줄에 들여쓴 블록. 파이썬은 `==` 하나뿐이고, `&&`→`and`, `!`→`not`, 괄호 대신 콜론과 들여쓰기.
</details>

**2. `17 / 3`, `17 // 3`, `17 % 3`의 결과와 각각의 뜻은?**

<details><summary>정답과 해설</summary>

`5.666...`(나눗셈, 항상 float), `5`(몫을 내림), `2`(나머지). 레벨 계산은 `xp // 100 + 1`, 바 수치는 `xp % 100`.
</details>

**3. `def f(x): x * 2` 를 호출해 `print(f(3))` 하면 무엇이 찍히나?**

<details><summary>정답과 해설</summary>

`None`. `return`이 없으므로 "함수 끝까지 가면 `None`을 돌려준다". `return x * 2`로 고쳐야 `6`.
</details>

**4. `if entries:` 는 언제 참인가? `entries = []`일 때는?**

<details><summary>정답과 해설</summary>

빈 리스트 `[]`는 거짓이므로 실행되지 않는다. 진릿값 검사 규칙: `None`, `False`, 0, 빈 시퀀스·컬렉션은 거짓. 내역이 하나라도 있으면 참.
</details>

**5. `trade_result(72000, 73500, 10, tax_rate=0.0018)`에서 `fee_rate`는 얼마로 계산되나?**

<details><summary>정답과 해설</summary>

기본값 `0.0`. 기본값 인자는 생략하면 정의할 때 적은 값을 쓰고, 뒤쪽 인자만 바꾸려면 `tax_rate=`처럼 키워드로 지정한다.
</details>
