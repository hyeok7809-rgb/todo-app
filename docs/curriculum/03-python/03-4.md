## 왜 배우나 (나에게 어떤 쓸모)

3-3까지 만든 스크립트는 파일 하나에 다 들어 있었다. 자동화가 늘면 "잔액 계산"은 가계부에도, 월별 리포트에도, 텔레그램 알림에도 필요하다. 복사해 붙이면 세 군데를 따로 고쳐야 한다. 해결은 회사와 같다. **부서(모듈)를 나누고 필요할 때 부른다.** `ledger.py`에 잔액 함수를 두고, 다른 파일에서 `import ledger`로 쓴다.

그리고 파이썬은 "배터리 포함(batteries included)" 철학이라(튜토리얼), 설치 없이 쓰는 표준 라이브러리가 넓다. 이 단원에서 고르는 셋은 자동화에서 매일 쓴다. `datetime`은 "오늘이 거래일인가, 장 마감 몇 분 전인가, 백업 파일 이름에 날짜 붙이기", `pathlib`은 "백업 폴더 만들고 파일 찾기", `os`는 "API 키를 코드 밖(환경변수)에 두기"(4-2의 핵심).

## 핵심 개념

### 1. 모듈(module)과 `import`

**한 줄 정의**: 모듈은 함수·변수 정의가 든 `.py` 파일이고, `import`는 그 파일을 불러와 이름으로 쓰게 한다.

**비유**: 부서별 서류철. 재무부 서류철(`ledger.py`)을 가져와 "재무부.잔액계산()"처럼 부른다.

**실제 예시** (튜토리얼 "모듈"의 `fibo` 예제 구조):

```python
import ledger                          # 모듈 전체. 쓸 때는 ledger.calculate_balance(...)
from ledger import calculate_balance   # 이름 하나만 직접 가져오기
import ledger as lg                    # 별명. pandas를 pd로 부르는 관례가 이것(3-6)
```

튜토리얼: `import fibo`는 "fibo에 정의된 함수 이름을 현재 이름 공간에 직접 추가하지 않는다." 그래서 `fibo.fib(1000)`처럼 모듈 이름을 앞에 붙인다. `from fibo import fib, fib2`는 직접 추가한다. `from os import *`처럼 전부 가져오는 방식은 튜토리얼이 "쓰지 말라"고 하는 것으로, 어떤 이름이 들어왔는지 알 수 없어진다.

**모듈을 찾는 순서**(`sys.path`, 튜토리얼): (1) 실행한 스크립트가 있는 폴더, (2) 환경변수 `PYTHONPATH`, (3) 설치 기본 경로(가상환경의 `site-packages`). 1번 때문에 3-1에서 경고한 "`json.py`라는 내 파일이 표준 `json`을 가리는" 사고가 난다. 또한 한 번 import한 모듈은 `__pycache__` 폴더에 컴파일 결과(`.pyc`)를 캐시한다. 지워도 되고 Git에도 안 올린다(`.gitignore`에 이미 넣었다).

**왜 중요한가**: 클로드가 만들어 주는 프로젝트는 처음부터 여러 파일이다. `from utils import ...`가 무슨 뜻인지 알아야 코드를 따라갈 수 있다.

### 2. `if __name__ == "__main__":`

**한 줄 정의**: 파일이 "직접 실행될 때만" 돌릴 코드를 감싸는 관용구. import될 때는 건너뛴다.

**비유**: 서류철 맨 뒤의 "이 서류를 단독으로 쓸 때의 사용 예". 다른 부서가 서류철을 빌려 갈 때는 그 부분을 실행하지 않는다.

**실제 예시** (튜토리얼):

```python
# ledger.py
def calculate_balance(entries): ...

if __name__ == "__main__":        # python ledger.py 로 직접 실행했을 때만
    import sys
    `import sys` 줄을 지우고 이 줄을 `    print(calculate_balance([{"type": "income", "amount": 1500000}]))`로 바꾸거나, 줄 끝에 `# sys.argv: 명령줄에서 넘긴 값 목록, [1]이 첫 인자` 주석을 붙인다.
```

튜토리얼: "명령줄을 해석하는 코드는 모듈이 'main' 파일로 실행될 때만 돈다." 직접 실행하면 `__name__`이 `"__main__"`, import되면 모듈 이름(`"ledger"`)이 된다.

**왜 중요한가**: 이 가드가 없으면 `import ledger`만 해도 테스트 출력이 줄줄 나오고, 4-4에서 스케줄러로 돌릴 때 엉뚱한 코드가 실행된다.

### 3. 패키지(package): 모듈을 담는 폴더

**한 줄 정의**: 폴더 안에 `__init__.py` 파일이 있으면 그 폴더는 패키지가 되고, `import 폴더.모듈`로 부른다.

**실제 예시**: 튜토리얼은 `sound/` 아래 `formats/`, `effects/`, `filters/` 하위 패키지 예제를 보여 주며 "`__init__.py`가 있어야 파이썬이 그 폴더를 패키지로 취급한다. 가장 단순하게는 빈 파일이면 된다"고 한다. 우리 식으로:

```
automation/
  company/
    __init__.py        # 빈 파일
    ledger.py          # 재무부
    health.py          # 인사부
  main.py              # from company import ledger
```

`import item.subitem.subsubitem`에서 "마지막을 제외한 각 항목은 패키지여야 한다." pip로 설치한 requests, pandas도 전부 패키지다.

### 4. `datetime`: 날짜와 시간

**한 줄 정의**: `date`(날짜), `datetime`(날짜+시각), `timedelta`(기간)로 날짜를 계산하고, `strftime`으로 문자열을 만들고 `strptime`으로 문자열을 읽는다.

**비유**: 달력과 계산기를 합친 것. "오늘부터 영업일 기준 D+2 결제일"을 손으로 세지 않는다.

**실제 예시** (datetime 모듈 문서의 예제 방식 `import datetime as dt`):

```python
import datetime as dt

today = dt.date.today()                    # "현재 지역 날짜"  → 2026-10-21
now = dt.datetime.now()                    # "현재 지역 날짜와 시각"
today.isoformat()                          # '2026-10-21'  (YYYY-MM-DD, app.js의 date와 같은 형식)
today.weekday()                            # 월=0 ... 일=6  → 2 (수요일)
today.strftime("%Y%m%d_%A")                # '20261021_Wednesday'  문자열로
dt.datetime.strptime("2026-10-21 15:30", "%Y-%m-%d %H:%M")   # 문자열 → datetime
today - dt.timedelta(days=7)               # 일주일 전 날짜
(dt.date(2026, 12, 1) - today).days        # 공부 시작일까지 41일
```

서식 코드(문서 표): `%Y` 네 자리 연도, `%m` 월, `%d` 일, `%H` 시(24시간), `%M` 분, `%S` 초, `%A` 요일 이름, `%a` 요일 약칭, `%B` 월 이름, `%y` 두 자리 연도, `%%` 퍼센트 기호. `timedelta(days=0, seconds=0, microseconds=0, milliseconds=0, minutes=0, hours=0, weeks=0)`는 "두 시각의 차이"를 나타내며 날짜에 더하고 뺄 수 있다. 날짜끼리 빼면 `timedelta`가 나오고 `.days`로 일수를 꺼낸다(튜토리얼 `age = now - birthday; age.days`).

**왜 중요한가**: 자동화는 항상 "언제"와 엮인다. 장중(9:00~15:30)에만 시세를 조회하고, 주말엔 건너뛰고, 백업 파일에 날짜를 붙이는 일 전부가 이 모듈이다.

### 5. `pathlib`: 경로를 객체로

**한 줄 정의**: `Path` 객체로 경로를 만들고(`/` 연산자로 이어 붙이고), 존재 확인·폴더 생성·읽기·쓰기·검색을 메서드로 한다.

**비유**: 0-1의 "주소"를 문자열로 다루는 대신 "주소가 적힌 명함"을 들고 다닌다. 명함에 "이 집이 있나?", "안에 뭐가 있나?"를 바로 물을 수 있다.

**실제 예시** (pathlib 문서 "기본 사용법"):

```python
from pathlib import Path

base = Path("backups")                     # 상대 경로. Path.cwd()는 현재 폴더, Path.home()은 홈
target = base / "2026-10-21" / "ledger.json"   # '/'로 하위 경로 (문서: os.path.join과 같은 역할)
target.parent.mkdir(parents=True, exist_ok=True)   # 중간 폴더까지 만들고, 있어도 에러 없음
target.write_text("[]", encoding="utf-8")  # 쓴 글자 수를 돌려준다
target.read_text(encoding="utf-8")         # 파일 내용 문자열
target.exists(), target.is_file()          # True, True
target.name, target.suffix, target.stem    # 'ledger.json', '.json', 'ledger'
list(base.glob("**/*.json"))               # 하위 폴더까지 모든 json
```

문서: `mkdir`의 `parents=True`는 "없는 상위 폴더를 필요한 만큼 만들고", `exist_ok=True`는 "이미 있어도 `FileExistsError`를 내지 않는다." Windows의 `\`와 Mac의 `/` 차이를 `Path`가 알아서 처리하므로 경로 문자열을 직접 조립하지 않는다.

**왜 중요한가**: "매일 백업 폴더 만들고 어제 파일 찾기"가 전부 `Path` 메서드 몇 개다.

### 6. `os`: 운영체제와 환경변수

**한 줄 정의**: `os.environ`은 "프로세스의 환경변수를 담은 매핑(딕셔너리처럼 쓰는 객체)"이고, `os.getenv(key, default=None)`은 "환경변수가 있으면 문자열로, 없으면 default를" 돌려준다.

**실제 예시** (os 모듈 문서):

```python
import os
os.getenv("MY_COMPANY", "(설정 안 됨)")   # 0-2에서 만든 환경변수 읽기
os.environ["HOME"]                        # Mac 홈 폴더 (문서 예시). Windows는 os.environ["USERPROFILE"]. 없는 키는 KeyError
os.name                                   # 'posix'(Mac/Linux) 또는 'nt'(Windows)
os.getcwd()                               # 현재 작업 폴더 (튜토리얼 예제)
```

**왜 중요한가**: 4-2에서 API 키를 코드에 적지 않고 환경변수로 넣는다. `api_key = os.getenv("KIS_APP_KEY")` 한 줄이 그 시작이다. 폴더·파일 작업은 `os.listdir`, `os.remove`, `os.rename`도 있지만 이 과정에서는 `pathlib`로 통일한다.

### 7. pip 패키지 쓰기와 import 정리

**한 줄 정의**: pip로 설치한 패키지는 표준 라이브러리와 똑같이 `import`하며, PEP 8은 import를 "표준 라이브러리 → 서드파티 → 내 모듈" 순서로 그룹 지어 한 줄에 하나씩 쓰라고 한다.

```python
import json                 # 1. 표준 라이브러리
from pathlib import Path

import requests             # 2. pip로 설치한 서드파티 (3-1에서 설치)

from company import ledger  # 3. 내 모듈
```

패키지를 고를 때는 pypi.org에서 이름을 확인하고 공식 문서를 연다. 설치 후 `python -m pip show 이름`으로 버전과 위치, `python -m pip freeze > requirements.txt`로 기록(3-1).

### 실습 1. 가계부를 모듈로 쪼개기 (30분)

3-2의 `ledger.py`에서 함수만 남기고, 실행 코드는 `__main__` 가드 안으로 옮긴다.

```python
# ledger.py - 재무부 모듈
XP_PER_ENTRY = 10
XP_PER_LEVEL = 100

def calculate_balance(entries):
    balance = 0
    for entry in entries:
        balance += entry["amount"] if entry["type"] == "income" else -entry["amount"]
    return balance

def format_money(number):
    return f"{number:,}원"

def level_info(xp):
    return xp // XP_PER_LEVEL + 1, xp % XP_PER_LEVEL

if __name__ == "__main__":
    sample = [{"type": "income", "amount": 1500000}, {"type": "expense", "amount": 9000}]
    print("모듈 단독 실행 테스트:", format_money(calculate_balance(sample)))
```

`main.py`를 만들어 불러 쓴다.

```python
# main.py - 3-3의 ledger-entries.json을 모듈로 집계
import json
from pathlib import Path

import ledger

entries = json.loads(Path("ledger-entries.json").read_text(encoding="utf-8"))
print("잔액:", ledger.format_money(ledger.calculate_balance(entries)))
level, xp_in_level = ledger.level_info(len(entries) * ledger.XP_PER_ENTRY)
print(f"Lv.{level} ({xp_in_level} / {ledger.XP_PER_LEVEL})")
```

`python ledger.py`는 테스트 한 줄을, `python main.py`는 잔액과 레벨을 출력한다. `main.py`에서는 "모듈 단독 실행 테스트"가 **안 나온다**는 것을 확인한다. 이게 `__name__` 가드다. 실행 후 `__pycache__` 폴더가 생긴 것도 본다.

### 실습 2. 날짜 도구 (30분)

`dates.py`. 매매 자동화의 "언제"를 전부 모아 본다.

```python
import datetime as dt

today = dt.date.today()
now = dt.datetime.now()
weekday_names = ["월", "화", "수", "목", "금", "토", "일"]

print("오늘:", today.isoformat(), weekday_names[today.weekday()] + "요일")
print("백업 파일명:", f"ledger_{today.strftime('%Y%m%d')}.json")
print("주말:", today.weekday() >= 5)

market_close = now.replace(hour=15, minute=30, second=0, microsecond=0)
print("장 마감까지:", market_close - now)

start = dt.date(2026, 12, 1)
print("공부 시작까지:", (start - today).days, "일")
print("일주일 전:", today - dt.timedelta(days=7))

last_trade = dt.datetime.strptime("2026-10-20 14:05", "%Y-%m-%d %H:%M")
print("마지막 매매 후 경과:", now - last_trade)
```

`replace(hour=15, ...)`는 문서의 `d.replace(day=26)`처럼 일부 요소만 바꾼 새 객체를 만든다. 장 마감 시각이 지났으면 음수 기간이 찍힌다. 그걸 `if now > market_close:`로 걸러 보라.

### 실습 3. 날짜별 백업 스크립트 (30분)

`backup.py`. `ledger.json`(3-3 실습 2)을 `backups/날짜/`에 복사하고, 백업 목록을 보여 준다.

```python
import datetime as dt
from pathlib import Path

SRC = Path("ledger.json")
BACKUP_DIR = Path("backups")

def backup(src=SRC):
    if not src.exists():
        print("원본이 없습니다:", src)
        return None
    folder = BACKUP_DIR / dt.date.today().isoformat()
    folder.mkdir(parents=True, exist_ok=True)
    dest = folder / src.name
    dest.write_text(src.read_text(encoding="utf-8"), encoding="utf-8")
    return dest

saved = backup()
print("저장:", saved)
for p in sorted(BACKUP_DIR.glob("*/*.json")):
    print(" ", p.parent.name, p.name, p.stat().st_size, "바이트")
```

두 번 실행해도 같은 날짜 폴더에 덮어쓰므로 에러가 없다(`exist_ok=True`). 여러 날 돌리면 `backups/` 아래 날짜 폴더가 쌓인다. 4-4에서 이 스크립트를 매일 자동 실행시킨다.

## 흔한 실수와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `ModuleNotFoundError: No module named 'requests'` | 가상환경 미활성 또는 다른 파이썬에 설치 | `(.venv)` 확인 후 `python -m pip install requests` |
| 내 모듈이 import되는데 엉뚱한 동작 | 표준 모듈과 같은 파일명(`json.py`, `random.py`) | 파일명 변경, `__pycache__` 삭제 |
| `import ledger` 했더니 테스트 출력이 줄줄 | `__main__` 가드 없음 | 실행 코드를 `if __name__ == "__main__":` 안으로 |
| `AttributeError: module 'datetime' has no attribute 'now'` | `import datetime` 후 `datetime.now()` | `datetime.datetime.now()` 또는 `import datetime as dt` 후 `dt.datetime.now()` |
| `ValueError: time data ... does not match format` | `strptime` 서식과 문자열 불일치 | 문자열과 `%Y-%m-%d` 등 서식 코드를 하나씩 대조 |
| Windows 경로 `"C:\new\test"`가 깨짐 | `\n`, `\t`가 이스케이프로 해석 | `Path("C:/new/test")` 또는 `r"C:\new\test"`(튜토리얼의 raw 문자열) |
| 다른 폴더에서 실행하니 파일을 못 찾음 | 상대 경로는 실행한 위치 기준 | `Path(__file__).parent / "파일"`로 스크립트 위치 기준 경로 사용 |

## 확인 퀴즈

**1. `import ledger`와 `from ledger import calculate_balance`의 차이는?**

<details><summary>정답과 해설</summary>

전자는 모듈 이름만 가져와 `ledger.calculate_balance()`로 부르고, 후자는 함수 이름을 직접 가져와 `calculate_balance()`로 부른다. 튜토리얼: `import fibo`는 "함수 이름을 현재 이름 공간에 직접 추가하지 않는다."
</details>

**2. `python main.py`를 실행했을 때 `ledger.py` 안의 `__name__` 값은?**

<details><summary>정답과 해설</summary>

`"ledger"`. `"__main__"`은 직접 실행된 파일(main.py)에만 붙는다. 그래서 `ledger.py`의 가드 안 코드는 실행되지 않는다.
</details>

**3. 내 프로젝트에 `random.py`를 만들고 `import random`을 하면 어떻게 되나?**

<details><summary>정답과 해설</summary>

표준 `random` 대신 내 파일이 import된다. 모듈 검색 순서 1번이 "실행한 스크립트의 폴더"라서 표준 라이브러리보다 먼저 찾는다. 파일명을 바꾼다.
</details>

**4. 오늘이 토요일인지 확인하는 식은?**

<details><summary>정답과 해설</summary>

`dt.date.today().weekday() == 5`. 문서: "월요일이 0, 일요일이 6." 주말 전체는 `>= 5`.
</details>

**5. `Path("backups") / "2026-10-21"` 폴더를 "있어도 에러 없이, 중간 폴더까지" 만드는 호출은?**

<details><summary>정답과 해설</summary>

`.mkdir(parents=True, exist_ok=True)`. 문서: `parents=True`는 없는 상위 폴더를 만들고, `exist_ok=True`는 이미 있어도 `FileExistsError`를 내지 않는다.
</details>
