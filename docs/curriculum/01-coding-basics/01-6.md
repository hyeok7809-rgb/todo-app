# 1-6. 배열과 객체: 목록과 묶음, push/filter/map/find, JSON이란

| 과정 | 1. 코딩의 기본 개념 (JavaScript로) |
|---|---|
| 예상 시간 | 4시간 |
| 선수 단원 | 1-5 |
| 경험치 | 80 |

## 이 단원을 마치면

- 배열(목록)과 객체(묶음)의 차이를 알고, `entries[0].title`처럼 "배열 안의 객체"에서 값을 꺼낼 수 있다.
- `push`, `filter`, `map`, `find`가 각각 무엇을 돌려주는지 알고, 콜백 함수와 함께 쓸 수 있다.
- "원본을 바꾸는 메서드"와 "새 배열을 돌려주는 메서드"를 구별한다.
- JSON이 무엇인지, `JSON.stringify`/`JSON.parse`가 왜 `localStorage` 앞뒤에 붙는지 설명할 수 있다.
- 보유 종목 목록 같은 "실제 데이터"를 배열+객체로 설계할 수 있다.

## 왜 배우나 (나에게 어떤 쓸모)

엑셀 시트를 떠올리자. 한 **행**이 매매 한 건(종목, 수량, 매수가, 매도가)이고, 시트 전체는 행의 **목록**이다. 자바스크립트에서 한 행은 객체(object), 시트는 배열(array)이다. 가계부의 `entries`가 정확히 "객체들의 배열"이고, 앞으로 만들 보유 종목, 루틴 체크, 학습 기록, API에서 받아 올 시세 데이터가 전부 이 모양이다.

`filter`, `map`, `find`는 엑셀의 "필터", "열 추가 수식", "찾기"다. 1-4의 반복문으로도 할 수 있지만, 이 세 개를 쓰면 한 줄로 끝나고 클로드가 써 주는 코드가 거의 전부 이 모양이라 **읽을 줄 알아야** 한다.

JSON은 데이터를 저장하거나 주고받을 때의 "표준 포장지"다. `localStorage`도, API 응답도, 설정 파일도 JSON이다. 2-5(저장), 2-6(네트워크), 4과정(API)의 공통 기초다.

## 핵심 개념

### 1. 배열(Array): 순서 있는 목록

**한 줄 정의.** 배열(array)은 여러 값을 순서대로 담는 목록이고, 각 값은 0부터 시작하는 번호(인덱스, index)로 꺼낸다. MDN: "JavaScript 배열은 0 인덱스입니다. 배열의 첫 번째 요소는 인덱스 `0`, 두 번째 요소는 인덱스 `1`, 마지막 요소는 배열의 `length` 속성 값에서 1을 뺀 값에 위치합니다."

**비유.** 관심 종목 리스트. 위에서부터 0번, 1번, 2번. 길이가 5면 마지막은 4번.

```js
const watch = ["삼성전자", "SK하이닉스", "카카오"];
watch[0];            // "삼성전자"
watch.length;        // 3
watch[watch.length - 1];   // "카카오" (마지막)
watch[5];            // undefined (없는 칸)
watch[1] = "현대차";  // 바꾸기
```

실무에서는 **같은 모양의 것들만** 담는다. 숫자 배열, 문자열 배열, 또는 같은 구조의 객체 배열.

### 2. 객체(Object): 이름표 붙은 묶음

**한 줄 정의.** 객체(object)는 "이름(키): 값" 쌍을 중괄호로 묶은 것이다. MDN 객체 안내서: "객체는 속성의 컬렉션이고, 속성은 이름('키')과 값 사이의 연결 관계입니다. 속성의 값이 함수인 경우에는 메서드라고 부릅니다."

**비유.** 엑셀 한 행에 열 이름이 붙은 것. "종목: 삼성전자, 수량: 10, 매수가: 71000".

**실제 예시.** `app.js`의 내역 한 건.

```js
const entry = {
  id: Date.now(),        // 키 id, 값 숫자
  type: "expense",
  title: "점심",
  amount: 9000,
  date: "2026-10-21",
};

entry.title;             // "점심"   (점 표기법)
entry["title"];          // "점심"   (대괄호 표기법. 키가 변수에 들어 있을 때 쓴다)
entry.memo;              // undefined (MDN: "객체에 할당되지 않은 속성은 undefined")
entry.memo = "회식";      // 없던 속성 추가
Object.keys(entry);      // ["id", "type", "title", "amount", "date", "memo"] (키 목록)
```

**배열 안의 객체 = 표.** `entries[0]`은 첫 행(객체), `entries[0].amount`는 첫 행의 금액 칸. 이 두 단계 접근이 앞으로 가장 많이 치는 코드다.

### 3. `push`: 끝에 넣기 (원본을 바꾼다)

**한 줄 정의.** `배열.push(값)`은 배열 끝에 값을 추가하고 **새 길이**를 돌려준다. MDN: "배열의 끝에 명시된 요소를 추가하고 배열의 새로운 길이를 반환합니다." `push()`는 "변이 메서드"로, 원본 배열 자체를 바꾼다.

```js
entries.push(entry);          // app.js addEntry. entries 자체가 길어진다
const n = entries.push(x);    // n은 새 길이. 배열이 아니다! (흔한 실수)
```

### 4. `filter`: 조건에 맞는 것만 (새 배열)

**한 줄 정의.** `배열.filter(검사함수)`는 검사함수가 참을 돌려준 요소만 모은 **새 배열**을 돌려주고, 원본은 그대로다. MDN: "주어진 배열의 일부에 대한 얕은 복사본을 생성하고, 주어진 배열에서 제공된 함수에 의해 구현된 테스트를 통과한 요소로만 필터링 합니다." 통과한 게 없으면 빈 배열.

```js
// app.js deleteEntry: id가 같은 것만 빼고 나머지를 남긴다
entries = entries.filter((entry) => entry.id !== id);

const expenses = entries.filter((e) => e.type === "expense");      // 지출만
const big = entries.filter((e) => e.type === "expense" && e.amount >= 100000);
```

검사함수는 1-5의 콜백이다. 요소 하나를 받아 `true`/`false`(또는 참/거짓 같은 값)를 돌려주면 된다. `deleteEntry`가 "삭제"를 "빼고 남기기"로 구현한 이유: 원본을 건드리며 반복하면 꼬이기 쉬운데(1-4 흔한 실수), 새 배열을 만들면 안전하다.

### 5. `map`: 하나씩 변환한 새 배열

**한 줄 정의.** `배열.map(변환함수)`는 각 요소에 변환함수를 적용한 결과로 **같은 길이의 새 배열**을 만든다. MDN: "호출한 배열의 모든 요소에 주어진 함수를 호출한 결과로 채운 새로운 배열을 생성합니다."

```js
const amounts = entries.map((e) => e.amount);                 // [9000, 120000, ...]
const labels  = entries.map((e) => `${e.date} ${e.title}`);   // ["2026-10-21 점심", ...]
Math.max(...amounts);                                         // 최대 금액 (...는 배열을 펼쳐 넣는 표기)
```

**`filter` vs `map`.** `filter`는 개수가 줄고 모양은 그대로, `map`은 개수는 그대로 모양이 바뀐다. 둘 다 원본은 안 바꾼다. 이어서 쓸 수 있다: `entries.filter(e => e.type === "expense").map(e => e.amount)`.

### 6. `find`: 첫 번째 하나만

**한 줄 정의.** `배열.find(검사함수)`는 검사를 통과한 **첫 요소 하나**를 돌려주고, 없으면 `undefined`다. MDN: "제공된 테스트 함수를 만족하는 첫 번째 요소를 반환합니다. 테스트 함수를 만족하는 값이 없으면 `undefined`가 반환됩니다."

```js
const target = entries.find((e) => e.id === 1761000000000);
if (target) {                 // undefined면 거짓 → 건너뜀 (1-3)
  console.log(target.title);
}
```

`filter`는 항상 배열(0개여도 `[]`), `find`는 요소 하나 또는 `undefined`. 이 차이를 섞으면 `Cannot read properties of undefined`가 난다.

### 7. 복사하기, 그리고 `reduce` 맛보기

`app.js`의 `render()`는 `entries.slice().reverse()`로 최근 것을 위에 보여준다. `reverse()`는 원본을 뒤집는 변이 메서드라서, 먼저 `slice()`로 복사본을 만든 뒤 뒤집는다. MDN: "JavaScript 배열 복사 연산은 얕은 복사본을 생성합니다." 겉 배열만 복사되고 안의 객체는 같은 것을 가리킨다는 뜻이다.

`reduce`는 1-4의 누적 패턴을 한 줄로 쓴 것이다. 클로드 코드에 자주 나오니 읽을 줄만 알아 두자.

```js
const total = expenses.reduce((sum, e) => sum + e.amount, 0);   // 0에서 시작해 sum에 누적
```

### 8. JSON: 데이터의 표준 포장지

**한 줄 정의.** JSON(JavaScript Object Notation)은 객체·배열·숫자·문자열·불리언·`null`을 **문자열**로 적는 규칙이다. MDN: "JSON은 객체, 배열, 숫자, 문자열, 불리언과 `null`을 직렬화하기 위한 구문으로, JavaScript 구문에 기반을 두고 있지만 분명한 차이점을 가지고 있습니다."

**비유.** 택배 포장. 물건(객체)을 그대로 보낼 수 없으니 규격 상자(문자열)에 담고(`stringify`), 받는 쪽에서 뜯는다(`parse`). 상자 규격이 전 세계 공통이라 파이썬, 서버, 엑셀 모두 뜯을 수 있다.

**실제 예시.** `app.js` 3번 구역.

```js
localStorage.setItem(STORAGE_KEY, JSON.stringify(entries));   // 배열 → 문자열 → 저장
entries = JSON.parse(localStorage.getItem(STORAGE_KEY));      // 저장된 문자열 → 배열
```

`localStorage`는 문자열만 저장할 수 있어서 이 변환이 필요하다. `JSON.stringify(entries)`의 결과는 이렇게 생겼다.

```json
[{"id":1761000000000,"type":"expense","title":"점심","amount":9000,"date":"2026-10-21"}]
```

**자바스크립트 객체와 JSON의 차이 (MDN JSON 문서).** 키는 반드시 큰따옴표. 작은따옴표 금지. 후행 쉼표 금지. 주석 불가. `undefined`와 함수는 표현할 수 없다(MDN `stringify`: "`undefined`, 함수, 심볼은 변환될 때 생략되거나(객체 안에 있을 경우) `null`로 변환된다(배열 안에 있을 경우)"). 잘못된 문자열을 `JSON.parse`하면 `SyntaxError`가 난다(1-7에서 대비책을 배운다).

### 실습 5. 보유 종목 포트폴리오 (30분)

`study/portfolio.js`.

```js
const holdings = [
  { name: "삼성전자",   qty: 30, buy: 71000, now: 72500 },
  { name: "SK하이닉스", qty: 5,  buy: 180000, now: 191000 },
  { name: "카카오",     qty: 20, buy: 40000, now: 38500 },
];

// map: 평가금액과 수익률을 붙인 새 배열
const valued = holdings.map((h) => ({
  ...h,                                   // 기존 속성 복사
  value: h.qty * h.now,
  rate: (h.now - h.buy) / h.buy * 100,
}));

// filter: 손실 종목만
const losers = valued.filter((h) => h.rate < 0);

// find: 특정 종목
const samsung = valued.find((h) => h.name === "삼성전자");

// reduce: 총 평가금액
const total = valued.reduce((sum, h) => sum + h.value, 0);

console.table(valued);
console.log("손실 종목:", losers.map((h) => h.name));
console.log("삼성전자 수익률:", samsung.rate.toFixed(2) + "%");
console.log("총 평가금액:", total.toLocaleString("ko-KR") + "원");
console.log(JSON.stringify(holdings, null, 2));   // 파일로 저장한다면 이 모양
```

`node portfolio.js`로 실행(Windows PowerShell, Mac 동일). `...h`는 객체의 속성을 펼쳐 복사하는 표기다(지금은 "복사해서 새 객체를 만든다"로만). 종목을 추가하고, `now`를 바꿔 가며 결과를 본다. 3과정에서 이 JSON을 파일로 저장하고 읽는다.

## 흔한 실수와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 첫 요소가 `undefined` | 인덱스를 1부터 셈 | 0부터. 마지막은 `length - 1` |
| `const arr2 = arr.push(x)` 뒤 `arr2.map` 에러 | `push`는 새 길이(숫자)를 반환 | `push`는 결과를 받지 않고 쓴다. 새 배열이 필요하면 `[...arr, x]` |
| `filter`했는데 원본이 그대로 | 원본을 안 바꾸는 메서드 | 결과를 변수에 받는다: `entries = entries.filter(...)` |
| `map` 결과가 전부 `undefined` | 콜백에 `return`이 없음 (중괄호 본문) | `(e) => e.amount` 또는 `{ return ...; }` |
| `Cannot read properties of undefined (reading 'title')` | `find`가 못 찾아 `undefined` | `if (target)`으로 확인 후 사용 |
| `JSON.parse` `SyntaxError` | 작은따옴표, 후행 쉼표, 깨진 문자열 | 키·문자열은 큰따옴표. 1-7의 `try...catch` |
| 저장했더니 일부 값이 사라짐 | `undefined`·함수는 JSON에 없음 | `null`이나 빈 문자열로 바꿔 저장 |
## 확인 퀴즈

**1. `entries[0].amount`를 두 단계로 설명하라.**

<details><summary>정답과 해설</summary>

`entries[0]`으로 배열의 첫 요소(객체 한 건)를 꺼내고, `.amount`로 그 객체의 `amount` 속성 값을 꺼낸다. "배열 안의 객체"는 표의 "행 안의 칸"이다.
</details>

**2. `push`, `filter`, `map`, `find` 중 원본 배열을 바꾸는 것은? 각각 무엇을 돌려주는가?**

<details><summary>정답과 해설</summary>

원본을 바꾸는 것은 `push`뿐(새 길이를 반환). `filter`는 조건을 통과한 요소들의 새 배열, `map`은 각 요소를 변환한 같은 길이의 새 배열, `find`는 조건을 만족하는 첫 요소 하나 또는 `undefined`.
</details>

**3. `app.js`의 `deleteEntry`는 왜 `filter`로 "빼고 남기기"를 하는가?**

<details><summary>정답과 해설</summary>

반복 중인 배열을 직접 수정하면 요소를 건너뛰는 등 꼬이기 쉽다. `filter`는 원본을 두고 새 배열을 만들므로 안전하고, 코드도 "id가 다른 것만 남겨라" 한 줄로 끝난다.
</details>

**4. `JSON.stringify({ a: 1, b: undefined })`의 결과는? 왜?**

<details><summary>정답과 해설</summary>

`'{"a":1}'`. JSON에는 `undefined`가 없어서 객체 속성이면 생략된다(MDN `stringify`). 배열 안이었다면 `null`로 바뀐다. 저장했다가 불러오면 그 속성이 사라져 있으니 주의.
</details>

**5. `localStorage` 앞뒤에 `JSON.stringify`/`JSON.parse`가 붙는 이유는?**

<details><summary>정답과 해설</summary>

`localStorage`는 문자열만 저장할 수 있다. 배열·객체를 저장하려면 문자열로 바꿔야 하고(`stringify`), 꺼낼 때는 다시 배열·객체로 되돌려야(`parse`) `.push`나 `.filter`를 쓸 수 있다.
</details>
