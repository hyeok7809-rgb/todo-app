# 커리큘럼 개요: AI 코딩 개발과 클로드, 기초부터

총 14개 과정, 66개 단원, 약 225시간. 하루 5시간 기준 약 3개월(12월~2월).

대상: 비전공 초보자. 목표: (1) 내 매매·생활 자동화 (2) 앱·서비스 만들어 판매 (3) 외주·프리랜스. 도구: 클로드 유료 구독, ChatGPT, Gemini.

## 단원 문서 공통 형식

모든 단원 파일은 아래 순서의 섹션을 가진다. 첫 줄 제목과 메타 표는 앱이 읽으므로 형식을 지킨다.

```markdown
# 8-3. CLAUDE.md와 메모리: 프로젝트 규칙 적어두기, 기억시키기

| 과정 | 8. Claude Code 기초 |
|---|---|
| 예상 시간 | 3시간 |
| 선수 단원 | 8-2 |
| 경험치 | 50 |

## 이 단원을 마치면
## 왜 배우나 (나에게 어떤 쓸모)
## 핵심 개념
## 따라하기
## 흔한 실수와 해결
## 확인 퀴즈
## 더 보기
## 숙제
```

- 경험치는 예상 시간 × 20 (2시간=40, 5시간=100).
- 설명은 '아주 자세히'. 비유와 표를 쓰고, 용어는 처음 나올 때 한글(영문)로 풀어 쓴다.
- 따라하기는 가능한 한 이 저장소(나의 1인 회사 앱)나 사용자의 실제 생활(주식·헬스·가계부)을 재료로 한다.
- 클로드·AI 관련 사실은 공식 문서를 확인하고 '더 보기'에 URL과 확인 날짜를 적는다.
