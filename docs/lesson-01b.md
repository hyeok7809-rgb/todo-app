# 1.5단계: 게임 스타일로 바꾸기

1단계 가계부를 그대로 두고, 그 **바깥에** 회사 지도 화면을 씌웠다.
`app.js`의 1~5번 구역(데이터, 저장, 계산, 그리기)은 거의 그대로다. 새로 들어간 건 세 가지.

## 1. 화면 전환: 숨겼다 보여주기

HTML에 화면이 두 개 있다. `#map-screen`(지도)과 `#ledger-screen`(재무부).
둘 중 하나에 `hidden` 클래스를 붙이면 CSS가 `display: none`으로 감춘다.

```js
function showScreen(screen) {
  mapScreen.classList.add("hidden");     // 둘 다 숨기고
  ledgerScreen.classList.add("hidden");
  screen.classList.remove("hidden");     // 하나만 보여준다
}
```

**클래스**는 요소에 붙이는 꼬리표다. 자바스크립트는 꼬리표를 붙였다 뗐다만 하고, 꼬리표가 어떻게 보이는지는 CSS가 정한다. 이 역할 분리가 웹 개발의 기본 습관이다.

## 2. 경험치와 레벨: 나눗셈 두 가지

```js
const xp = entries.length * 10;          // 기록 1건 = 10 경험치
const level = Math.floor(xp / 100) + 1;  // 100으로 나눈 몫 → 레벨
const xpInLevel = xp % 100;              // 100으로 나눈 나머지 → 이번 레벨에서 채운 양
```

`/`는 나누기, `%`는 **나머지**다. 230 경험치라면 `230 / 100 = 2.3` → 내림하면 2 → +1 해서 Lv.3, 나머지 30이 바에 표시된다.
게임의 레벨 시스템은 거의 다 이 두 줄이다.

## 3. 모션: CSS가 움직인다

자바스크립트가 매 프레임 그리는 게 아니라, CSS에 "이렇게 움직여"라고 적어두면 브라우저가 알아서 움직인다.

- **경험치 바**: `.xp-fill`에 `transition: width 0.6s` 를 적어뒀다. 자바스크립트가 너비만 바꾸면 0.6초에 걸쳐 차오른다.
- **캐릭터 걷기**: `@keyframes walk`에 시작 위치와 끝 위치를 적고, `animation: walk 6s infinite alternate` 로 6초마다 왕복시킨다.
- **+10 EXP 팝업**: `@keyframes pop-up`으로 1초 동안 위로 떠오르며 투명해진다. 자바스크립트는 요소를 만들어 붙이고 1초 뒤 지우기만 한다.

### 캐릭터는 그림 파일이 아니다

`.player`의 `box-shadow`에 점을 하나씩 찍어서 그렸다. `8px 0 #3a2a1a` 는 "오른쪽 8px, 아래 0px 위치에 갈색 점". 4px 단위로 격자를 채운 것이다.
그림 파일을 쓰는 게 보통이지만, 지금은 "픽셀 아트가 결국 점의 좌표와 색"이라는 걸 보여주려고 이렇게 했다. 7단계에서 진짜 그림으로 바꾼다.

## 숙제 (2개)

1. **캐릭터 넥타이 색 바꾸기** — `style.css`에서 `#e84545`로 찍힌 점 두 개(`12px 20px`, `16px 20px`)의 색을 바꿔라.
2. **레벨업 기준 바꾸기** — `app.js`의 `XP_PER_LEVEL`을 50으로 바꾸면 어떻게 되는지 확인하고, 다시 100으로 돌려놓아라.
   이걸 통해 "숫자 하나를 이름 붙여서 맨 위에 모아두는 이유"를 느껴보자.
