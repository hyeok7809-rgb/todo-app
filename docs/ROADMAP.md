# 자기관리 앱 로드맵

혼자 사는 개인 투자자를 위한 자산관리 앱을 만들면서 코딩 기초를 배운다.
설치 없이 브라우저만으로 동작하는 HTML / CSS / JavaScript로 시작한다.

| 단계 | 기능 | 배우는 것 | 상태 |
|---|---|---|---|
| 1 | 가계부: 수입/지출 입력, 목록, 잔액, 새로고침해도 유지 | HTML 폼, 배열, 함수, localStorage | ✅ 완료 |
| 2 | 카테고리별 합계, 이번 달 요약 | 반복문, 조건문, 날짜 다루기 | |
| 3 | 자산 현황: 계좌별 잔고, 순자산 | 객체, 여러 데이터 묶기 | |
| 4 | 월별 그래프 | 외부 라이브러리 가져다 쓰기 | |
| 5 | 데일리 루틴 체크 + 연속 달성일 | 지금까지 배운 것 종합 | |
| 6 | 데이터 내보내기 / 가져오기 (백업) | 파일, JSON | |

## 진행 방식

1. 한 단계에 한 가지 개념만 새로 배운다.
2. 각 단계마다 `docs/lesson-N.md`에 설명과 숙제를 적는다.
3. 숙제를 먼저 해 보고, 막히면 다음 세션에서 같이 푼다.
4. 매매 끝나고 하루 30분~1시간 분량으로 쪼갠다.

## 실행 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 된다. 서버도, 설치도 필요 없다.
