# 나의 1인 회사 — 로드맵

혼자 사는 개인 투자자가 **자기 자신을 회사처럼 운영**하는 게임형 자기관리 앱.
기록을 남길수록 경험치가 쌓이고 회사 레벨이 오른다. 단계가 끝날 때마다 부서(방)가 하나씩 열린다.
최종 목표는 각 부서에 AI 직원을 배치해서 24시간 돌아가는 회사로 키우는 것.

설치 없이 브라우저만으로 동작하는 HTML / CSS / JavaScript로 시작한다.

| 단계 | 열리는 방 | 기능 | 배우는 것 | 상태 |
|---|---|---|---|---|
| 1 | 재무부 | 가계부: 수입/지출, 잔액, 새로고침해도 유지 | HTML 폼, 배열, 함수, localStorage | ✅ |
| 1.5 | 회사 지도 | 게임 스타일 지도(상태 바·부서 방·길·범례), 레벨/경험치, 오늘 상태, 캐릭터 모션 | CSS 클래스, 애니메이션, 화면 전환 | ✅ |
| 1.6 | 회사 지도 (픽셀 오피스 리디자인) | 앉은 자리(의자→캐릭터→책상), 벽 띠·문·널빤지 바닥, 사장실 카펫, 걷는 캐릭터 바운스, 상태 바 재배치 | 글자 격자로 그리는 픽셀 그림(`sprites.js`), 데이터 배열로 화면 만들기(`ROOMS`), `data-*` 속성, 작은 도우미 함수, `try/catch` | ✅ |
| 2.5 | 재무부 확장 | 카테고리별 합계, 이번 달 요약 | 반복문, 조건문, 날짜 다루기 | |
| 3 | 자산관리부 | 계좌별 잔고, 순자산 | 객체, 여러 데이터 묶기 | |
| 4 | 기획부 | 월별 그래프, 리포트 | 외부 라이브러리 가져다 쓰기 | |
| 2 | 인사부 · 교육부 | 데일리 루틴 체크와 연속 달성일, 커리큘럼 66단원 진도와 예정일, 세 부서 경험치 합산 (순서를 앞당김: 12월 공부 시작에 필요해서) | 날짜를 키로 쓰는 객체, while 반복, 계산값은 저장하지 않기, 부서마다 파일 나누기 | ✅ |
| 5 | 백업 | 데이터 내보내기/가져오기(JSON 파일) | 파일, JSON | |
| 6 | 자산관리부 확장 | 월별 순자산 추이 | 날짜별 스냅샷 | |
| 7 | 그림 교체 | 무료 픽셀 에셋 또는 AI 생성 이미지로 방·캐릭터 꾸미기 | 이미지 다루기, 스프라이트 | |
| 8 | AI 직원실 | Claude API로 부서별 AI 직원 배치 | API 호출, 서버 기초 | |

## 진행 방식

1. 한 단계에 한 가지 개념만 새로 배운다.
2. 각 단계마다 `docs/lesson-N.md`에 설명과 숙제를 적는다.
3. 숙제를 먼저 해 보고, 막히면 다음 세션에서 같이 푼다.
4. 매매 끝나고 하루 30분~1시간 분량으로 쪼갠다.

## 실행 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 된다. 서버도, 설치도 필요 없다.
